# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work.
Harassment, personal attacks and discriminatory language are not tolerated.

Report problems privately to the maintainer via the contact on the GitHub
profile or through a private security advisory on the repository. Reports are
handled confidentially. Maintainers may remove comments, close discussions,
or block contributors who violate this code.
